    FAQ
    Questions, answered.
    
    
    
      
    Do I need to know how to code?
    No. You run one command to start it, then everything happens in the app: type your idea, watch, approve. You need Node 20+ and Claude Code installed and signed in.
    
      
    What does it cost?
    Garage is free and always will be. Otto's work runs through your own Claude Code, so it uses your Claude plan or API key. The app shows what each run is worth at API prices (our full demo build: $0.43) and lets you cap every run.
    
      
    Which Claude do I need?
    Whatever you've signed in to Claude Code with. Garage never sees your login; it just runs your own Claude Code. Using a Claude plan with third-party tools is covered by Anthropic's terms, so give them a read.
    
      
    Does Otto send anything on his own?
    Never. He only drafts. When you approve a post or email, it opens in X, LinkedIn, Threads or your mail app with the text filled in, and you press send.
    
      
    Can Otto mess up my computer?
    He runs sandboxed: his file tools are locked to that business's folder, he can't run commands or code, and none of your own Claude Code settings, hooks or plugins load. He can search and read the web.
    
      
    Where do my files live?
    In ~/Documents/Garage, one folder per business: brand.json, logo.svg, site/, research.md, posts.json, outreach.json, deck.html, sheet.csv.
    
      
    What can't it do yet?
    Answer a phone line, run ads, make videos, take payments, or take texts from your phone. Pull requests welcome.
